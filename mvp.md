# MVP MoneyDash

Первая версия позволяет пользователю загрузить историю операций из CSV и понять, сколько денег поступило и ушло, как суммы менялись по месяцам и на какие категории пришлись основные расходы.

## Use case «Проанализировать доходы и расходы по CSV»

**Актор** — пользователь, который анализирует личный бюджет или операции небольшого бизнеса.

**Предусловия** — MoneyDash запущен локально, у пользователя есть CSV в поддерживаемом формате.

### Основной сценарий

1. Пользователь открывает страницу импорта, выбирает CSV и нажимает кнопку загрузки.
2. Приложение отправляет файл на сервер. Сервер проверяет записи и сохраняет набор в памяти.
3. Пользователь попадает на дашборд. По умолчанию отображаются все операции набора.
4. Пользователь видит общий доход, общий расход, разницу между ними, график доходов и расходов по месяцам и диаграмму расходов по категориям.
5. Пользователь задаёт период, категорию или оба фильтра. Карточки и оба графика обновляются по одной и той же выборке. Сброс фильтров возвращает сводку по всем операциям набора.

**Результат** — пользователь получает сводку по загруженным операциям и может сравнить доходы и расходы за выбранный период.

### Альтернативные сценарии

- Файл пуст или не соответствует формату. Приложение остаётся на странице импорта и показывает причину. Для ошибки в записи сообщает номер строки, чтобы пользователь мог исправить CSV и повторить загрузку. Частичный импорт не выполняется.
- Дата начала периода позже даты окончания. Приложение показывает ошибку поля и сохраняет предыдущую сводку.
- Фильтры не находят операций. Карточки показывают нули, вместо графиков появляется сообщение с возможностью сбросить фильтры.
- Ссылка на набор устарела, например после перезапуска сервера. Дашборд предлагает вернуться к импорту и загрузить файл заново.

## Формат CSV

CSV в UTF-8 с запятой в качестве разделителя. Обязательные столбцы — `date`, `type`, `category`, `amount`. Столбец `description` необязателен. Файл должен содержать хотя бы одну операцию.

| Столбец | Допустимое значение |
| --- | --- |
| `date` | Существующая календарная дата в формате `YYYY-MM-DD` |
| `type` | `income` для дохода или `expense` для расхода |
| `category` | Непустое название категории |
| `amount` | Положительная сумма в рублях с точкой в качестве десятичного разделителя и максимум двумя знаками после неё |
| `description` | Произвольный текст, допускается пустое значение |

## Границы первой версии

### Входит в MVP

- Загрузка одного CSV за раз и проверка всего файла до импорта.
- Сводные карточки с доходами, расходами и их разницей.
- Интерактивные графики с подсказками по точкам и столбцам. Линейный график показывает динамику по месяцам, столбчатый — расходы по категориям.
- Фильтрация по диапазону дат и одной категории, сброс фильтров.
- Временное хранение операций на сервере в рамках локального запуска.

### За пределами MVP

- Поддержка Excel, JSON и автоматической загрузки из банков.
- Ручное добавление и редактирование операций, объединение нескольких файлов.
- Несколько валют, пересчёт по курсу и прогнозирование расходов.
- Аккаунты, разграничение доступа, постоянное хранение и история импортов.
- Экспорт отчётов и настройка собственных графиков.
